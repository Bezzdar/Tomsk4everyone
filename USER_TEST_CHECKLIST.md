# Tomsk4everyone — User Test Release Gate

Сборка получает статус **USER TEST READY** только после прохождения CI и этого короткого ручного smoke-check.

## Автоматические условия

- [ ] Python-файлы компилируются без синтаксических ошибок.
- [ ] Все JavaScript-файлы проходят `node --check`.
- [ ] `docker compose config` валиден.
- [ ] Стек разворачивается на чистом volume.
- [ ] `/api/health` подтверждает доступность backend и PostgreSQL.
- [ ] Регистрация и авторизация работают.
- [ ] Черновик сохраняется со статусом `draft`.
- [ ] Статья проходит `draft → submitted → needs_revision → submitted → approved → published`.
- [ ] Публичная статья открывается по `slug`.
- [ ] Пользователь не может изменить чужую статью.
- [ ] `<script>` и HTML-обработчики событий не сохраняются в статье.
- [ ] Повторное выполнение задания не начисляет награду второй раз.
- [ ] После restart контейнеров опубликованный материал остаётся доступным.

## Ручная проверка интерфейса

### Анонимный пользователь

- [ ] Главная страница открывается без ошибок в консоли.
- [ ] Каталог статей открывается.
- [ ] Пользовательская опубликованная статья открывается по прямой ссылке.
- [ ] Профиль перенаправляет на вход.

### Обычный пользователь

- [ ] Можно зарегистрироваться с новым email.
- [ ] После регистрации открывается профиль.
- [ ] Можно изменить имя.
- [ ] Можно создать и сохранить черновик.
- [ ] После перезагрузки черновик остаётся в профиле.
- [ ] Можно отредактировать черновик и отправить его.
- [ ] После возврата модератором виден комментарий.
- [ ] Статью можно исправить и повторно отправить.
- [ ] После публикации ссылка из профиля открывает тот же материал, что и каталог.

### Модератор

- [ ] Черновики пользователей не попадают в очередь модерации.
- [ ] У `submitted` доступны только «вернуть на доработку» и «одобрить».
- [ ] Возврат на доработку требует комментария.
- [ ] У `needs_revision` нет кнопки публикации.
- [ ] У `approved` доступна публикация.

### Задания

- [ ] Тест «Легенды Томска» сохраняет выполнение и начисляет 25 кедрокоинов один раз.
- [ ] Фотоохота и «Истории жителей» явно сообщают, что проверка результата пока не включена.
- [ ] В интерфейсе нет кнопки, позволяющей получить награду за эти задания без проверки.

## Функции, сознательно исключённые из первого теста

- комментарии и рейтинги статей;
- фоторепортаж и маршрут как отдельные шаблоны публикации;
- покупка бонусов и партнёрский сценарий;
- автоматическое подтверждение фото- и текстовых заданий;
- отдельная административная панель управления пользователями;
- мобильное приложение и полнотекстовый поиск.

Их отсутствие в этой сборке является осознанным ограничением, а не дефектом релиза.
